# Faith Njoki Njenga Portfolio

Improved static portfolio website for Faith Njoki Njenga, positioned as a technology educator and creative technologist.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation and sticky header behavior
- `assets/` - local copies of the portfolio images

## Preview

Open `index.html` in a browser. The site is static, so it does not need a dev server.

## Notes

The redesign reflects the client documentation: digital skills training, robotics education, web development, creative digital design, technology integration, experience, professional impact, and future expansion.
